# OPTIMIZE WIN 10\n\nBlack Edition, manual-first Windows 10 utility. Includes bilingual dark UI, live CPU/RAM/disk monitoring, running-process list, optional Above Normal priority, confirmed temporary cleanup, restore-point request, and startup scan.\n\nBuild on Windows with Python 3.10+: install requirements.txt and PyInstaller, then build main.py as a one-file windowed executable. GitHub Actions builds the EXE and stores it as a workflow artifact. Restore points may require Administrator rights and System Protection. This app does not promise FPS gains or disable Windows services.\n
